# 龍山派 曾氏族譜・3D 祠堂

three.js 打造的立體世系祠堂（單檔 PWA）。網址：https://kftseng2oo1.github.io/3d-zupu/

- 神位牌直書（名諱放大），背面生平、照片、字號；在世家人以宣紙卡呈現
- 「三省堂」匾額與楹聯、家族沿革碑、每世字輩牌、靈骨塔位側殿
- 忌日（含農曆）當天牌位發光；上香、語音口述、祭祀紀錄
- 金爐・燒金紙（底列「金爐」、香案右側小金爐、供奉面板、地藏殿／眾靈祠、除夕）：刈金、大銀、壽金、福金；往上滑或輕點把金紙送進爐口，紙會飛入、燒出焦洞化成灰，有燒紙劈啪聲與手機震動（Android 震動；iPhone 需 iOS 18 以上的觸覺回饋）。每疊 50 張，「整疊化」一次燒完；顯示累計張數、疊數、今日張數（存在本機），離開時記入祭祀紀錄「燒金紙 N 張」，燒過後 3D 金爐火勢轉旺一陣子
- 開場卷軸、逐世導覽、存圖海報
- 除夕祭祖（底列「除夕」或祭祀面板）：家中神明廳——觀音彩繪、祖宗長佑子孫賢／佛力永扶家門盛、歷代祖考妣神位、佛龕觀音、鹽燈、蝴蝶蘭；下桌擺鮮花、素果三盤、糖果五盤、飲料、三牲、發粿插春。流程：擺供品 → 鐘鼓齊鳴上供祈福 → 上香三拜 → 祈福圓滿（記入祭祀紀錄・歷代祖先）；除夕當天開啟時會出現提示

## 軟體更新

發佈新版時把 `sw.js` 的 `CACHE` 版號 +1（例：`3d-zupu-v33` → `v34`）。
App 開啟、回到前景、每 30 分鐘會自動檢查；有新版時上方跳出「軟體更新」，按「立即更新」才切換並重新載入（不會打斷祭祀中的畫面）。底列「更新」可手動檢查並顯示目前版本。

## 資料來源

與族譜紀念堂（https://kftseng2oo1.github.io/zupu/）同網域，會自動讀取紀念堂存在瀏覽器的資料（localStorage `ancestorApp_v28`）：
祖先名冊、神位文字、生卒忌日、生平、照片、配偶、塔位、家族沿革。內建資料寫在 `index.html` 的 `PEOPLE`；匾額、楹聯、字輩在 `HALL`。

## 祭祀雲端（arcar `/zupu`）

上香紀錄與語音要全家共用，需部署已併入 `/zupu` 的 arcar Worker **v30**（`kftseng2oo1/grandpa` 的 `worker/arcar-worker_v30.js`，含燒金紙紀錄），並在 arcar 新增 KV 綁定 `ZUPU_KV`。
`worker/zupu-module.js` 是同一份後端的獨立模組原稿。燒金紙紀錄（type `paper`）需 v30 以上；舊版後端不認得時只記在本機，其他雲端功能不受影響。

未部署時自動改為本機模式（上香只記在該裝置，語音無法上傳）。
